7. Basic Auth Setup Instructions:
   # Generate htpasswd entry with bcrypt (recommended):
   htpasswd -nbC 10 admin your-secure-password

   # Create or update the secret:
   kubectl create secret generic {{ .Release.Name }}-basic-auth-secret \
     --from-literal=htpasswd="$(htpasswd -nbC 10 admin your-secure-password)" \
     -n {{ .Release.Namespace }}

   # Or use an existing secret by setting basicAuth.existingSecretName in values.yaml
