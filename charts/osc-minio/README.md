## Usage

Define necessary values:

```yaml
global:
  oscServiceAccount: testuser
  imagePullSecret:
    password: SECRET
  ingress:
    minio:
      api: minio-api.k8.osc.edu
      console: minio-console.k8.osc.edu
  auth:
    allowGroups:
      - group
  alert:
    receiver: group
  minio:
    auth:
      rootUser: "minioadmin"
      rootPassword: "supersecret"
```
