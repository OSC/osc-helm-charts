## Usage

Define necessary values:

```yaml
global:
  oscServiceAccount: testuser
  imagePullSecret:
    password: SECRET
  ingress:
    host: testuser.k8.osc.edu
    hostAlias: testuser.osc.edu
    apiHost: minio-api.k8.osc.edu
  auth:
    allowGroups:
      - group
  alert:
    receiver: group

minio:
  auth:
    rootUser: "minioadmin"
    rootPassword: "supersecret"
```
